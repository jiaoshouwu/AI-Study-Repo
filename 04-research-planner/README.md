# Day 4 - Research Planner

## Goal

Break a broad research topic into
smaller questions, research each one,
and synthesize the evidence.

## Architecture

Topic
→ Planner
→ Questions
→ Web Search
→ Evidence
→ Writer
→ Report

## What I Learned

1. Planning and execution are different.
2. A planner converts a goal into tasks.
3. Search results are observations.
4. Evidence should be collected before writing.
5. The writer should be grounded in evidence.
6. Hosted web_search differs from my custom
   Python tools.
